- Java 21  
- Spring Boot 3.3.2

- PostgreSQL (основной сервис)  
- Spring Data JPA, Hibernate Validator (основной сервис)  
- MapStruct, Lombok, REST API, JUnit

---

## Структура проекта

- **ewm-main-service/** — основной сервис (бизнес-логика, работа с БД, API)  
- **ewm-stats-service/** — сервис статистики (сбор и анализ данных о просмотрах)

---

## Возможности

### Публичное API
- Поиск и фильтрация событий (сортировка по просмотрам или датам) 
- Просмотр краткой и полной информации о событиях  
- Получение категорий и подборок событий  
- Фиксация просмотров в сервисе статистики  

### Закрытое API (авторизованные пользователи)
- Добавление, редактирование и просмотр событий  
- Подача и подтверждение заявок на участие в событиях  

### Административное API
- Управление категориями (добавление, изменение, удаление)  
- Управление подборками (добавление, удаление, закрепление)  
- Модерация событий (публикация, отклонение)  
- Управление пользователями (добавление, активация, просмотр, удаление)  

### Сервис статистики
- Запись данных о запросах к API  
- Предоставление статистики по эндпоинтам за выбранные даты  

### Дополнительная функциональность
- Добавление и просмотр комментариев к событиям

## Запуск проекта

1. **Склонируйте репозиторий:**

    ```
    git clone https://github.com/your-username/explore-with-me.git
    ```

2. **Перейдите в папку проекта:**

    ```
    cd explore-with-me
    ```

3. **Соберите проект:**

    ```
    mvn clean install
    ```

4. **Запустите сервисы (в отдельных терминалах):**

    - **Основной сервис:**

        ```
        cd ewm-main-service
        mvn spring-boot:run
        ```

    - **Сервис статистики:**

        ```
        cd ../ewm-stats-service/server
        mvn spring-boot:run
        ```

    **Примечание:**  
    Вы также можете запускать сервисы из корневой папки, указав путь к `pom.xml`:

    ```
    mvn spring-boot:run -f ewm-main-service/pom.xml
    mvn spring-boot:run -f ewm-stats-service/server/pom.xml
    ```
